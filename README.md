# 小二乘法挑戰王：Google Sheets 龍虎榜版

## 功能
- 每次隨機 10 題，每題 1 分，滿分 10 分。
- 龍虎榜只記錄名字、班別、分數。
- 同一名字及班別只保留最高分。
- Google Sheets 作中央成績表，不同裝置可查看同一份榜單。
- 乘法概念：a × b 代表「a 的 b 倍」，即 b 組、每組 a 個；例如 3 × 4 = 3 + 3 + 3 + 3 = 12。

## 1. 建立 Google 試算表
1. 到 https://sheets.google.com 建立新試算表，命名「小二乘法挑戰王龍虎榜」。
2. 不用預先建立欄位，程式會自動建立 `Scores` 工作表及「名字、班別、分數」標題。

## 2. 加入 Apps Script
1. 在試算表選「擴充功能」→「Apps Script」。
2. 刪除預設程式，將本資料夾 `GoogleAppsScript.gs` 全部內容貼入編輯器並儲存。

## 3. 部署 Web App
1. Apps Script 右上角「部署」→「新增部署作業」。
2. 類型選「網頁應用程式」，執行身分選「我」。
3. 「誰可以存取」選「任何人」，否則 GitHub Pages 遊戲不能讀寫榜單。按「部署」並完成授權。
4. 複製部署網址，使用以 `/exec` 結尾的網址，不要用 `/dev`。

## 4. 連接遊戲
1. 打開 `config.js`，將 `PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE` 換成你的完整 `/exec` 網址。
2. 將本資料夾所有檔案上載到 GitHub repository 根目錄，覆蓋舊檔案。
3. 開啟 GitHub Pages，完成一場測試後檢查試算表；按「更新榜單」可重新讀取成績。

## 日後更新
學生提交後會自動寫入 Google Sheets。老師可直接編輯試算表三欄；遊戲按「更新榜單」便會重新讀取。

## 私隱與限制
此 Web App 需要對任何持有遊戲網址的人開放，因此沒有登入驗證的人可能提交假分數。請只收集名字、班別、分數，不要加入學號、電話、電郵等敏感資料。若要防止灌分，需額外設計登入或存取控制。
