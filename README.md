# 小二乘法挑戰王

- 開始前只需輸入名字及班別。
- 每次隨機 10 題，每題 1 分，滿分 10 分。
- 龍虎榜只記錄：名字、班別、分數；不收集學號或其他資料。
- 同一名字及班別只保留最高分，顯示前 20 名。
- 乘法概念統一：a × b 表示「a 的 b 倍」，即 b 組、每組 a 個。例如 3 × 4 = 3 + 3 + 3 + 3 = 12。
- 龍虎榜使用瀏覽器 localStorage，只在同一部裝置、同一個瀏覽器顯示；不同學生裝置的分數不會自動合併。
